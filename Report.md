## 4. Limitations

- Student performance is a limited public dataset; relationships in it do not establish causation.
- The grade predictor uses only five input features and is an educational demonstration, not a reliable tool for deciding a real student's academic future.
- Fashion-MNIST experiments use subsets of the original dataset and only a small number of epochs to keep laptop runtime manageable. Results may differ with more data, more training, or different hardware.
- A single train/test split and one random seed cannot establish that a model will generalize equally well to all future data.
